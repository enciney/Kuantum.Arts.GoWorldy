# mobile-developer Agent

## Description
React Native mobile app developer for GoWorldy project

## Instructions
- Develop mobile app using Expo
- Implement authentication screens (login, register, forgot password)
- Build navigation structure matching API endpoints
- Integrate with existing API at http://localhost:3000
- Use TypeScript

## API Endpoints
```
POST /api/auth/register
POST /api/auth/login
GET  /api/forum/countries
GET  /api/guide/steps/:countryId
GET  /api/admin/dashboard
```
