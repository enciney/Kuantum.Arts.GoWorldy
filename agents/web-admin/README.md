# web-admin Agent

## Description
React admin dashboard for GoWorldy project

## Instructions
- Build React admin dashboard
- Manage users, roles, forum, guide stats
- Connect to /api/admin endpoints
- Use TypeScript + React

## API Endpoints
```
GET  /api/admin/dashboard
GET  /api/admin/users
GET  /api/admin/users/:id
PATCH /api/admin/users/:id/role
GET  /api/admin/config
GET  /api/admin/forum/stats
GET  /api/admin/guide/stats
```
